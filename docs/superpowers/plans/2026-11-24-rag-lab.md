# RAG-lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public repo of 13 Jupyter notebooks (00–12), backed by a growing `raglab/` package, that takes developers from RAG-from-scratch to a FastAPI service and an agentic RAG, on a fictional hotel corpus written for this repo.

**Architecture:** Notebooks are authored as jupytext percent-format `.py` files in `notebooks/_src/`. They are built and executed into `notebooks/*.ipynb`, which are committed with outputs. Shared code graduates into `raglab/` under a never-break-existing-behaviour rule. `raglab.bootstrap` rebuilds any index a notebook needs, so every notebook runs standalone. Diagrams are Archify JSON → HTML → PNG captured with Playwright.

**Tech Stack:** Python 3.12, uv, OpenAI SDK 3.x, numpy, pandas, chromadb 1.5, LangChain 1.5 (+ langchain-openai 1.8, langchain-chroma 1.2, langchain-text-splitters 1.2, langchain-community 0.4, langchain-classic 1.1), langgraph 1.2, ragas 0.4, rank-bm25 0.2, sentence-transformers 6 (extra), langchain-postgres 0.0.19 + psycopg 3 (extra), FastAPI 0.165 + uvicorn (extra), pypdf 7, beautifulsoup4, fpdf2 2.9, jinja2, pyyaml, pydantic-settings 2.16, jupytext 1.19, nbclient, playwright 1.65 (dev), Archify skill (Node 22).

**Spec:** `docs/superpowers/specs/2026-11-24-rag-lab-design.md`. Read it alongside this plan. Section numbers below (§n) refer to it.

## Global Constraints

- **No automated tests** (owner's global preference overrides TDD). Verification is done by building and executing notebooks, running scripts, and manual checks with the expected output stated in each step.
- **Nothing from the reference lab:** no code, prompt text, data, names, or mention/credit of the lab or its provider anywhere in the repo. Write everything fresh (§1, §2).
- **Stability rule (§6.2):** once a task ships a public `raglab` function, later tasks never change its signature or default behaviour. They only add new functions or opt-in kwargs.
- **Self-containment (§6.3):** every notebook starts with the 3 standard setup cells and runs top-to-bottom from a fresh clone, in any order, with only `OPENAI_API_KEY` + core install (extras only where §11a says).
- **Budget (§10):** a default run of any one notebook costs ≤ $0.05. The full run (`RAGLAB_FULL_RUN=1`) of all notebooks costs ≤ $2 in total. Every notebook ends with `cost.report()`.
- **Honest numbers (§10):** markdown commentary about scores is written *after* the full run and must match the committed numbers.
- Python `>=3.11,<3.14`. All file I/O uses `encoding="utf-8"`. Use `pathlib` only, with no hard-coded separators.
- Embedding model `text-embedding-3-small`. Chat model from `RAGLAB_CHAT_MODEL`, default `gpt-6-luna` called with `reasoning_effort="none"` and **no `temperature`** (it's a reasoning model).
- Legacy LangChain retrievers are imported from `langchain_classic` and labelled "legacy API" in notebook text.
- Each notebook shows at least one Archify diagram through a `show_diagram()` code cell, never a relative markdown image (§9, §11b).
- Brand is **Token Hotels & Resorts**; hotels are named "Token <City>"; README + every corpus doc carry a fictional/no-affiliation note (§7).
- Commit after each task directly on **`main`** (owner's choice; no feature branch). Never push unless asked.

## Review Focus

1. **Missing / invalid key or OpenAI quota error.** Setup cell 1 and `llm.client()` must print one friendly sentence ("Set OPENAI_API_KEY in .env — see README") and not a stack trace. 429 responses are retried by the SDK (`max_retries=5`). → verification in Task 1.
2. **Fresh clone / any order / edited corpus.** `ensure_index` must build when `.cache/` is absent and rebuild when the corpus fingerprint changes. It must never reuse a stale index silently. → verification in Task 6.
3. **Windows encoding.** Corpus files contain non-ASCII characters (em dashes, accented city names such as "Reykjavík"). Every read and write is explicit UTF-8, and the PDF text survives extraction. → verification in Tasks 3 and 5.
4. **Optional pieces absent:** no `[rerank]` extra, no `DATABASE_URL`, no Docker. Affected cells skip with an instruction message, and the notebook still completes. → verification in Tasks 10 and 12.
5. **Service misuse:** no or wrong `X-API-Key` → 401. Question over 1,000 chars → 422. Unanswerable question → 200 with `found=false`. Unsupported upload type → 415. More than 30 requests/min → 429. → verification in Task 14.

  - `llm.check_budget(estimated_usd: float, *, limit_usd: float = 0.05) -> bool` prints the estimate and returns `True` if it is under the limit or `settings.full_run`.
  - `display.show_chunks(docs, n: int = 3, width: int = 300) -> None`.
  - `display.show_diagram(name: str, width: int = 900, interactive: bool = False) -> None` displays `IPython.display.Image` of the PNG (embedded in the output, so it renders on GitHub, Colab and Kaggle), followed by a markdown link `../diagrams/{name}.html`. With `interactive=True` it displays the HTML inline instead.
  - `tools/build_notebooks.py [NAMES...] [--no-execute] [--timeout 900]` runs jupytext `notebooks/_src/X.py` → `notebooks/X.ipynb` and then executes it with nbclient (cwd `notebooks/`). With no names given, it builds all of them.

  - `chunking.add_context_prefix(docs) -> list[Document]` prepends `"{hotel_name} — {doc_type}\n\n"` when `hotel_name` is set, and returns new docs.

### Task 6: Notebook 03, raw Chroma + bootstrap

- Create: `raglab/store_chroma.py`, `raglab/bootstrap.py`, `notebooks/_src/03_vector_search.py`, `diagrams/vector_search.*`

**Interfaces:**
